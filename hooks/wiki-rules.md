## LLM 위키

LLM 위키 볼트: `{{VAULT_PATH}}`

`llm-wiki` 플러그인 스킬(`wiki-query`·`wiki-log`·`wiki-ingest`·`wiki-lint`)은 위 경로를 볼트로 쓴다.

### 작업 참조 ← 위키

**의미 있는 작업을 시작하기 전에, 위키에 이미 답이 있는지 먼저 본다** —
사용자가 매번 "위키 찾아봐" 하게 만들지 않는다. `wiki-query` 스킬로 참조한다.

**참조한다**: 과거에 풀었을 법한 문제 · 이 환경 고유의 함정 · 특정 설비·시스템·서버·과제 ·
예전에 내린 설계 결정을 다시 건드릴 때.

**참조하지 않는다**: 위키와 무관한 일반 지식 질문 · 즉석 일회성 작업 · 사소한 조회.

### 작업 기록 → 위키

프로젝트를 불문하고, 의미 있는 작업이 끝나면 **당신이 먼저 제안한다** —
"위키에 남길까요?" 사용자가 매번 요청하게 만들지 않는다. 승인하면 `wiki-log` 스킬로 쓴다.

**남긴다**: 되풀이될 문제를 해결했을 때 · 이 환경만의 특성을 발견했을 때 ·
설계 결정을 내렸을 때(특히 택하지 않은 대안과 그 이유) · 삽질이 길었을 때

**남기지 않는다**: 단순 조회 · 일회성 명령 · 이미 코드·문서·git 이력에 있는 것

제안 시점은 **작업이 일단락된 직후**다. 다음 주제로 넘어간 뒤에는 늦다.

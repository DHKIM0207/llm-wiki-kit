LLM 위키 플러그인 설치 안내

Claude Code·Codex로 작업하면 Claude가 알아서 정리해 쌓아가는 개인 지식 위키

  • 작업이 끝나면 "위키에 남길까요?"라고 먼저 묻고, 승인하면 기록합니다.
  • 비슷한 작업을 시작할 때 예전 기록을 먼저 찾아봅니다.
  • 문서·자료를 넣으면 요약하고 서로 연결해 둡니다.

1준비물

항목구분설명
Claude Code 또는 Codex필수Claude Code: Pro 이상 요금제 또는 API 키 / Codex: Codex CLI
Git필수Windows는 Git for Windows (Claude Code 사용자는 이미 설치됨)
Obsidian선택위키를 그래프·링크로 편하게 보고 싶을 때

2설치

Claude Code — 대화창에서 
/plugin marketplace add DHKIM0207/llm-wiki-kit
/plugin install llm-wiki@llm-wiki-kit
Codex — 터미널에서 
codex plugin marketplace add DHKIM0207/llm-wiki-kit
codex plugin add llm-wiki@llm-wiki-kit

3처음 설정

  1. 새 세션을 열고 LLM 위키 만들어줘 라고 입력합니다.
  2. 볼트 위치(예: C:\Users\<이름>\Documents\my-wiki), 이름, 도메인을 물어보면 답합니다. 폴더 구조를 만들어 줍니다.
  3. 새 세션부터 자동 참조·기록 제안이 적용됩니다. Codex는 ~/.codex/AGENTS.md에 규칙을 붙일지 물어보면 승인하세요.
  4. Obsidian이 있다면 그 폴더를 "폴더를 보관소로 열기"로 엽니다.

4이렇게 쓰세요

자료 넣기볼트의 raw/에 문서를 넣고 → "이거 위키에 넣어줘"
질문"예전에 ○○ 어떻게 했었지?", "○○ 관련 정리해줘"
점검"위키 점검해줘" — 모순·끊긴 링크·다음에 조사할 것 제안
작업 기록끝나면 Claude가 먼저 물어봅니다. 직접 "위키에 기록해줘"도 가능
참고
  • 업데이트: 자동 업데이트는 기본으로 꺼져 있습니다. Claude Code는 /plugin → Marketplaces → llm-wiki-kit → Enable auto-update를 켜 두거나, 터미널에서 claude plugin marketplace update llm-wiki-kit 후 claude plugin update llm-wiki@llm-wiki-kit. Codex는 codex plugin marketplace upgrade llm-wiki-kit 후 codex plugin add llm-wiki@llm-wiki-kit
  • 위키는 각자 PC에만 있는 개인 위키입니다. 백업이 필요하면 볼트 폴더를 본인 GitHub 비공개 저장소에 연결하세요.
  • raw/에 넣은 원본은 git에 올라가지 않으니 따로 백업하세요.
